# Тестовая сборка «Адвокат» для Windows

[Скачать ZIP для Windows 10/11 x64](https://github.com/greengo18/lite.github.io/raw/refs/heads/windows-builds/AdvokatLocal-Windows-x64-0.1.zip)

Распакуйте всю папку и запустите `AdvokatLocal.exe`. Python устанавливать не нужно. Это экспериментальный прототип для вымышленных документов DOCX; на настоящей Windows комплект еще не проверен.

Описание выпуска и ограничения: https://github.com/greengo18/lite.github.io/releases

Контрольная сумма указана в соседнем файле `.sha256`.
