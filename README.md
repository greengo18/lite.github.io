# Адвокат — тестовая версия для Windows

Переносимый прототип для локального обратимого обезличивания документов Word DOCX.

Сборка и инструкция доступны в разделе [Releases](https://github.com/greengo18/lite.github.io/releases). Распакуйте всю папку из ZIP и откройте `AdvokatLocal.exe`. Python устанавливать не требуется.

Windows 10/11 x64. Пока используйте только вымышленные документы. Это экспериментальная версия с ограниченным набором детекторов и обязательной ручной проверкой. PDF и сканы не поддерживаются. Программа не определяет допустимость раскрытия адвокатской и иной тайны.

Код проверен на Linux; переносимый комплект еще не проверялся на настоящей Windows. Подробности и контрольная сумма находятся в описании выпуска.
